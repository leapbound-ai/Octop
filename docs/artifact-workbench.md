# 产物工作台

工作台跟踪成功工具调用发布到 Agent 工作区的文件。主导航进入 `/artifacts`，可以搜索和筛选产物、查看原文件、更新标题与标签、归档或忽略，或者回到来源对话。

## 列表与详情

- 列表首屏显示简要统计、看板和常用筛选。标签与时间在「更多筛选」，自动收录在收录设置。详情返回时保留列表的筛选和页码。
- 「从默认列表隐藏」更新显示状态，操作后可撤销，也可在「已隐藏」筛选下恢复。
- 详情优先展示标题、来源、摘要和正文。自动生成的选品文件名在标题中使用场景名，原始名称和路径在「文件信息」。已有人工标题和摘要照常显示。
- 「关联资料」优先显示可点击的关系列表，图形按需展开。「评论与评价」先显示评论，「历史版本」提供版本对比和新对话草稿。没有看板时可直接新建并收藏。

## 采集

- 标准文件工具使用已有参数和输出提取规则。其他工具可通过返回工作区文件路径进入索引。通过 shell 写盘且输出没有返回文件路径时，工作台无法发现该文件。
- 默认收录文档类文件。收录设置按当前登录用户保存。全部模式也排除隐藏目录、构建缓存和临时目录。
- 数据库按 Agent、对话及工作区相对路径去重，并从对话表取得用户归属。重复采集保留人工标注及状态。聊天文件栏继续按原有规则记录。
- 选品报告由同一轮的 `run_breadth_research` 数据和随后成功的报告写入关联，保存分档候选、出处及业务验证字段。其它文件使用工作区预览。

## API

`GET /api/artifacts` 返回用户自己的分页列表，支持状态、类型、Agent、标签、关键词、时间和排序。`/agents`、`/stats` 和 `/settings` 提供筛选项、计数及收录设置。通过 `/{artifact_id}` 读取详情或标注，`/{artifact_id}/status` 更新状态，`/{artifact_id}/thread` 获取来源对话。文件读取和下载仍走工作区 API，沿用现有访问规则。

## 派生与版本

- 从详情选择历史版本并派生新任务，工作台用现有对话入口打开一个新线程，将任务与有长度上限的历史资料放入可编辑草稿。发送前可以查看或删改资料。原始产物权限与目标 Agent 权限均会核对。
- 结构化结果保存 JSON 版本。标准写入和编辑工具记录 Markdown、纯文本、HTML、CSV 及 JSON 文件的 UTF-8 快照，上限为 64,000 字符。内容相同的相邻版本归并。版本迁移回填已有结构化记录。旧文本首次派生时尝试从原工作区保存首版。
- 版本选择可与同一产物的另一版或派生时选定的来源版本对比。新线程产生的产物自动记录来源及选中的版本。
- 工作台关键词搜索覆盖用户自己的标题、摘要、标签、结构化数据及文本快照，支持中文子串检索。
- `GET /api/artifacts/{artifact_id}/versions` 列出版本，`GET /api/artifacts/{artifact_id}/versions/{revision}` 返回快照。`POST /api/artifacts/{artifact_id}/derive` 根据 `request_id` 创建可重试的派生对话，返回草稿所需的摘录。

## 自定义看板与引用图谱（v28）

- 用户可以新建、重命名、删除私有看板。产物卡片可以拖到看板名称上收藏，也可以使用收藏菜单（适用于键盘与触屏）。同一产物可加入多个看板；重复收藏不重复记录，也不清除已有置顶。置顶仅影响当前看板，排在普通产物前面。
- 看板沿用工作台的状态、关键词、类型等筛选。看板数量包含所有状态；默认列表仍只显示活跃产物。移出看板或删除看板均不删除原始产物。
- 详情页允许搜索自己可见的活跃产物并建立有方向的引用。图谱同时展示引用、反向引用以及已有 parent_id 派生关系，箭头指向参考或来源。点击节点跳转到该产物，再继续探索下一层。引用可移除；派生来源不能在此删除。
- 单次图谱最多返回 100 条相邻边，超限时显示提示；循环引用合法但禁止自引用。所有查询及变更核对当前用户归属；删除产物会级联移除看板成员及引用边。
- 新增 `/api/artifacts/boards`、`/boards/{board_id}`、`/boards/{board_id}/items/{artifact_id}`；列表增加 `board_id` 筛选。新增 `/{artifact_id}/graph` 与 `/{artifact_id}/references`。
- SQLite / PostgreSQL 迁移对为 028；本地已使用 v27，故采用增量迁移。已有 `refs` 字段未曾用于记录关系；本版本以 `artifact_references` 表为引用关系的唯一来源。
- 本轮不实现三路任务一键派生，保留已有单任务草稿入口。

## 协作与审阅（v29）

- 产物详情支持 1–5 星评分、待审阅／已采用／已否决，以及文字评论。评论使用客户端幂等 ID，重复提交不会生成重复记录；评论只能由产物所属用户查看和删除。
- “用于后续偏好参考”是每份产物的明确开关，默认开启。关闭后仍保存审阅记录，但不会进入后续偏好证据集合。删除评论也会撤回该评论的偏好证据。
- v29 新增 `artifact_reviews` 与 `artifact_comments`，评论和审阅会记录当时选中的产物版本（如果存在），便于回看反馈针对的内容。
- 本轮完成本地持久化和界面入口；自动把历史反馈注入模型上下文需要额外确认数据向模型提供方传输的授权，当前暂不启用。
