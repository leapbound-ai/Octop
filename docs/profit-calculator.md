# 拼多多利润计算器

入口为 OCTOP 工作台的「利润计算器」。用券后单笔成交价估算每单利润。商品按件填写时，采购包规格和每单件数默认各为 1，批量采购可以展开调整。常用费用用店铺默认值复用，商品价格和采购参数独立填写。

- 退款损失为退款率 ×（退款额外物流 + 不可回收货值），货值含分摊后的采购价和入库物流。退款额外物流只填尚未计入日常发货成本的部分。退款率大于 0 时，需明确填写残值率与退款额外物流，填 0 表示确认该项为零。售后预留用于退款之外的额外成本。
- 以退款后净利为主口径。保本售价和目标净利价都含预计退款，向上取到分。成本红线按其他输入不变、净利等于零反推，允许的最大可输入值向下取到分或 0.01 个百分点。保本单量向上取整。
- 平台扣点按比例随售价变化。Brand OS 冻结样本的断言包含 3 元平台费，当前退款路径省略绝对额字段时会算出 50.50 元。OCTOP 在 100 元售价下用明确的 3% 扣点复现冻结断言 47.50 元，并校验显式 0% 的结果。
- 计算在浏览器实时完成。店铺默认值按账号保存并保留历史，恢复旧版本会生成新版本。历史方案保存完整输入及当时的结果，支持同一账号跨设备查看、对比和导出。当前编辑草稿保存在当前浏览器，按账号隔离。
- OCTOP API 仅存取，不调用 Brand OS 或代理工具。SQLite 和 PostgreSQL 使用同版本迁移。
