# 供应商询价工作台

`/supplier-rfq` 提供询价单与供应商档案。一次询价记录一个商品和多家店铺。从产物工作台的选品报告可以带入商品，零售标价已核时预填计划售价，提交前可调整。

- 新建时保存品类话术清单。计划售价和月销量只留在询价单中，复制话术时不会发给店铺。
- 粘贴原话后可仅保存，也可保存并解析。每次修改形成新回复版本，同一份原话重复保存复用当前版本。解析失败保留原文。
- 条款只有找到连续原文引证，且显示值来自该引证时，才显示为已明确。后端返回 Unicode 字符位置。历史回复按版本保留。
- 已解析的条款可逐项人工修正，保留供应商原话和 AI 提取结果。比价、导出、供应商历史和追问采用修正后的条款，也可在原回复里恢复 AI 结果。人工修正随当前回复版本保存。
- 已有店铺可复用，重复店名按账号及归一化名称合并。录入时先匹配同商品历史，仍未确认的历史条款优先追问。归档后保留对比与导出，重新开启后可继续记录。
- 对比表显示最新回复，可从条款跳到原话，支持下载 Markdown。到手成本待实际成本数据齐全后可在利润计算器中核算。

迁移 031 为 SQLite 与 PostgreSQL 建立账号隔离的询价单、店铺及回复表。回复版本直接承担报价历史。迁移 032 为回复版本新增独立的人工修正字段。
